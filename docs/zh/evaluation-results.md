# 评测结果

[English](../evaluation-results.md)

这是 **2026-11-09** 在 DSH `0.2.2-rc.1`、路由 `opencode-go/deepseek-v4.1-flash` 上用内置 `engineering-recall-v1` 合成语料真实执行 `/snapcompact benchmark` 的结果；不读取或上传任何私有会话历史。

## 结果

下表是 08:11 UTC 的一次运行。同一语料更早的一次运行记录在“运行间波动”里，避免本页混用两次数字。

| 方案        | 状态     | 精确匹配 | 帧数 |  耗时 | 说明                                                           |
| ----------- | -------- | -------- | ---: | ----: | -------------------------------------------------------------- |
| original    | measured | 8/9      |    — |  9.4s | 完整语料                                                       |
| native-text | measured | 7/9      |    — | 12.5s | 原生摘要基线                                                   |
| snapcompact | measured | 8/9      |    6 | 16.3s | 2048×2040 帧，估算 checkpoint 8,786 token；`deepseek-estimate` |

原生摘要使用 112 input、14,464 cacheRead、1,476 output token（合计 16,052）。视觉组没有调用 handoff，只做本地渲染和读图。

benchmark 直接调用视觉方法；在正常会话中，它还必须通过配置的 `minCompressionRatio`（按引擎自己的估算），所以历史较短时，即使实测 checkpoint 更小，也可能回退文本。

## token 口径

以下是 token 总量，不是美元账单。prompt 合计遵循 DSH 合同：input + cacheRead + cacheWrite。一次性生成是产出 checkpoint 的成本，每轮读取是之后携带的上下文。

| 方案        | 一次性生成 | 每轮读取 | 首次压缩合计 | 3 轮合计 |
| ----------- | ---------: | -------: | -----------: | -------: |
| original    |          0 |   14,357 |       14,357 |   43,071 |
| native-text |     16,052 |      523 |       16,575 |   17,621 |
| snapcompact |          0 |    8,152 |        8,152 |   24,456 |

- 原生摘要在首轮之后每轮都更小，但生成它一次性花了约 1.6 万 token。只拿 523 token 的读取量对比视觉 checkpoint 的 8,152 token，会漏掉这次生成调用。
- 视觉 checkpoint 在第一次压缩时更便宜（8,152 对 16,575）。在这份语料上，摘要约在第 2 到第 3 轮之间反超。
- cacheRead 通常比新输入便宜，图片计价也因路由而异；这些总量不是账单。

## 解释

- **可读性：** 两次运行视觉组都是 8/9，与原文一致。原生摘要本次 7/9、更早一次 8/9，因此单次对比不足以证明稳定的召回优势。另一次真实检查让模型读帧中段的标记，模型正确回答 `ID_40`；随后用 `snapcompact_recall` 逐字取回了被截断中段的一行。
- **token 经济性：** snapcompact 没有生成调用、稳态占用更大；原生摘要有一次生成调用、稳态占用更小。哪个更便宜取决于使用轮次、缓存计价和图片价格。
- **适用场景：** 长历史、图片 token 便宜的路由、不能接受有损摘要的保真场景，以及不希望发起摘要调用的溢出恢复。
- **运行间波动：** 同一语料更早一次运行（07:46 UTC）测得 original 8/9 / 14,357 prompt token，native-text 8/9 / 639，snapcompact 8/9 / 8,149、6 帧。两次运行的精确匹配会差 1 题。
- **评测边界：** 固定合成语料，不代表所有语言、provider 或真实长项目。
